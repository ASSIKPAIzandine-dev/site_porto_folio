## Fonctionnalités

- Design moderne sombre (style développeur pro)
- 100 % responsive (mobile, tablette, desktop)
- Menu mobile animé
- Animations au scroll
- Liens GitHub sur chaque projet
- Téléchargement du CV
- Sections : Accueil, À propos, Compétences, Projets, Formation, Contact

## Lancer localement

Ouvre simplement `index.html` dans un navigateur, ou utilise un serveur local :

```bash
npx serve .
# ou
python3 -m http.server 8000
```

## Note WhatsApp

Dans `index.html`, remplace le numéro WhatsApp factice `22800000000` par ton vrai numéro (format international sans + ni espaces).

Exemple : `https://wa.me/22890123456`
